原型索引 web 小程序 手机端 admin
本目录是 UI/UX 重做的第一交付物：四端原型 + 11 套主题。每页顶部下拉可切主题，URL 加 #theme=midautumn 可直接定位截图；切换只改颜色与图案令牌，布局结构一个都不动。

一、四端原型

web 前台（5 屏）

首页 / 商品详情 / 下单支付 / 个人中心（含主题设置）/ 状态图。对应 web/src/pages/*，路由与接口在每屏标注里写明。

 小程序（6 屏）

首页 / 商品详情 / 行情 / 下单与开箱 / 我的 / 状态图。真机框 375×780，胶囊与 tabbar 均为原生控件示意。

 手机端 mobile（6 屏）

与小程序共用组件层，差异页：我的订单（订单列表 + 待支付重付）。现状跟随系统暗色，提案为增加主题选择。

 admin 后台（5 屏）

仪表盘 / 商品 / 订单（退款 modal）/ 漏斗分析（新增）/ 设置（含主题运营位、爬虫站点总览）。

二、主题清单与色板（11 套）

每张卡片用自身主题渲染，可直接看到实际效果；色板顺序：背景 / 表面 / 次表面 / 主色 / 主色弱 / 文字。

三、验证方式

打开浏览器直接打开任意 .html（静态文件，无构建、无第三方素材）
切主题页面右上下拉，或 URL 追加 #theme=autumn（可复现截图）；选择写入 localStorage
换主题不改布局结构令牌写在 :root 且不被任何主题覆盖，详见 ../ui-system.md
