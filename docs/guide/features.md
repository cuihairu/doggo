# 功能总览

[English](/guide/features.en) | [简体中文](/guide/features)

本文列出 Doggo 规划的功能全景与当前状态。功能基线来自[原有平台功能分析](../design/legacy-analysis),按开源版的定位做了取舍与扩展。

## 资讯聚合(自建)

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| CS2 / Dota 2 资讯源 | 官方公告、更新日志、赛事动态;源为配置数据,内置种子源 | 已完成 |
| 抓取管道 | 定时调度、抓取、去重、入库(`Doggo.Scraper`) | 已完成 |
| 资讯展示 | 列表/详情(`GET /api/news`) | 已完成 |
| 运营内容 | 公告、Banner、自定义文章(接口 + 后台管理);web 首页展示公告/Banner、文章详情页 `/articles/:id`,小程序与手机端首页展示公告 | 已完成 |

原有平台只有一个通用文章管理模块;CS2 / Dota 2 的多源资讯聚合是开源版的**新增能力**。

## 饰品行情(基于 vapor)

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 市场价格同步 | 通过 vapor 拉取 Steam 市场挂牌价,失败自动退避;不可用时读最近快照 | 已完成(vapor 联调待其可用) |
| 价格快照与日线 | 每次同步落快照,价格不变不重复落;按日折叠成 OHLC | 已完成 |
| 行情列表与搜索 | `GET /api/market/items`(关键词、游戏、类型、分页,含最新价);web 行情页提供关键词搜索框、游戏/类型筛选与「加载更多」翻页 | 已完成 |
| 价格趋势展示 | `GET /api/market/items/{id}/prices` 按日 OHLC 序列 | 已完成 |
| 汇率 | `GET /api/exchange-rates`;web 行情列表对非 CNY 价格按汇率显示约合人民币 | 已完成 |
| vapor Webhook | `POST /api/vapor/webhook`(HMAC-SHA256 验签、时间窗校验、Redis 幂等去重) | 已完成 |
| 饰品资料库 | 饰品资料由 vapor 同步(名称、市场名、图标) | 已完成(vapor 联调待其可用) |
| 箱子 / 套餐 / 内容物 / 数量档 | 实体已建,资料导入链路未实现 | 未实现 |

## 外部价格爬虫(自建)

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 第三方站点价格抓取 | `Doggo.PriceCrawler` 独立模块,配置驱动的 HTML 适配器,并入 Scraper 进程 | 已完成 |
| 调度与频控 | per-site 串行循环、夜间窗口、robots 门禁、熔断、指数退避、原始行 90 天清理 | 已完成 |
| 清洗去重 | 币种归一、价格上界、60 分钟窗口去重、滚动中位数疑点标记 | 已完成 |
| 趋势与比价 | 日收盘、日环比、周同比、区间涨跌;与站内快照价差报告 | 已完成 |
| admin 接口 | `/api/admin/price-crawl`:maps 列表与审阅、prices 序列、spread-report 比价 | 已完成 |

## 开箱系统

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 批次代开 | 批次/座位售卖:乐观锁占座、售罄判定、vapor 开箱提交、结果事件落奖品,详见[开箱系统设计](../design/case-opening) | 已完成(vapor 联调待其可用) |
| 奖品记录 | 饰品完整字段(资产 ID/磨损/稀有度/估价)、我的奖品列表/详情、行情价快照关联、开箱日志查询 | 已完成 |
| 库存管理 | 座位状态机(售卖中→…→完成)、批次乐观锁、跳步/回退拒绝 | 已完成 |
| 饰品取回 | Steam 交易报价交付,交易链接校验 | 已完成(vapor 联调待其可用) |
| 商品列表与搜索 | `GET /api/products`(关键词、类型、分页,仅上架商品);web 商店页提供关键词搜索框、类型筛选与「加载更多」翻页,小程序与手机端商品列表提供关键词搜索与加载更多 | 已完成 |
| roll 房 | 模板开房(登录领取/每单参与/邀请码等 8 种规则)、加入校验、到期开奖(AliasMethod 权重抽取)、饰品或积分发放、按模板自动滚动下一期,`GET /api/roll/rooms`、`GET /api/roll/rooms/{id}` | 已完成(饰品奖品先发记录,实际交付走取回流程;vapor 联调待其可用) |

## 用户与订单

| 功能 | 说明 | 状态 |
| --- | --- | --- |
| 用户体系 | 注册登录、Steam OpenID / 微信小程序登录、JWT | 已完成 |
| 订单 | 状态机(待支付→待结算→待取回→取回中→已完成,取消/退款)、超时未支付取消、对账补偿(卡单自动退款/取回回退重试) | 已完成 |
| 交易链接与饰品取回 | 交易链接 CRUD 与格式校验(web 与手机端/小程序用户中心均可绑定),经 vapor 发起取回,完成/失败回调推进订单 | 已完成(vapor 联调待其可用) |
| 支付 | 可插拔支付接口,内置 Mock 渠道(支付链接、回调验签、幂等、退款),真实渠道按需接入 | 已完成(mock 渠道) |
| 积分 / 优惠券 | 金币流水(用户端三端均可查明细,后台抽屉另有全量视图)、优惠券领取与抵扣、过期策略、领券中心(三端用户中心可领券)、兑换码换积分或优惠券(web/小程序/手机端用户中心均有入口) | 已完成 |
| 邀请与签到 | 邀请返利(`GET /api/invites` 本人返利明细与累计,web/小程序/手机端用户中心可见)、每周周期签到 | 已完成 |
